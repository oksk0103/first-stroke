# 첫 획

세 살 아이의 디지털 공책. 어른이 먼저 쓰고 아이가 따라 씁니다.

**학습 효과를 주장하지 않습니다. 아빠가 만들고 싶어서 만든 공책입니다.**

## 처음 한 번

1. 아이패드 사파리에서 https://oksk0103.github.io/first-stroke/ 를 열고, 공유 → **홈 화면에 추가**. (사파리 탭으로만 쓰면 일주일 안 열었을 때 저장된 게 지워질 수 있어요. 홈 화면 앱은 괜찮습니다.)
2. 홈 화면에서 앱을 열고 **왼쪽 위 모서리를 손가락 두 개로 3초** 누르면 어른 메뉴가 열려요. (한 손가락으로는 안 열립니다 — 아이가 눌러도 아무 일 없게.)
3. 어른 메뉴에서 ① **가족 이름** — 맨 앞은 아이, 그 뒤가 어른들(예: 태이, 루아, 엄마, 아빠, 할머니) ② **오늘 어른** ③ 오늘 글자 **목소리 한 번 녹음**(3초). 홈 화면 앱에서 마이크가 안 되면 음성 메모로 글자를 한 번 녹음해서 '파일로 올리기'. 녹음이 없으면 기기 음성이 대신 읽어요.
4. 닫기. 끝.

## 매일

- 홈에 **오늘 글자 하나**가 떠 있어요. 첫날은 아이 이름의 한 글자. 끝낸 뒤 아이가 스스로 다시 누르면 다음 글자가 나와요(기본은 제한 없음, 어른 메뉴에서 하루 한두 글자로 제한할 수도 있어요). 멈추는 건 아이가 정합니다.
- 홈 오른쪽 위의 이름(루아·엄마·아빠)이 **오늘 주묵색으로 먼저 쓰는 사람**. 바꾸려면 이름을 **1초 길게** 누르세요. 언니도 됩니다.
- 글자를 탭 → 조각 맞추기(안 해도 10초면 넘어감) → 어른이 붉은 글씨로 씀 → '아이 차례' → 아이가 먹색으로 씀(덮어 써도 됨) → 펜을 떼면 2초 뒤 글자 소리 → 15초 가만히 있으면 종이가 접혀 끝.
- 홈 왼쪽 아래 **종이 더미**를 누르면 아이가 쓴 종이를 넘겨보는 책. 마지막 빈 종이에서 홈으로. 숫자·날짜·지우기 없음, 14일 지나면 빠집니다.
- 아이패드 펜슬 권장, 손가락도 됩니다. 펜을 쓰는 동안 손바닥은 무시해요. 펜슬은 누르는 힘, 손가락은 속도에 따라 먹 굵기가 달라지고, 쓸 때 사각사각 소리가 나요(어른 메뉴에서 끌 수 있음).
- 홈 글자 아래 **한글 · ABC · 123** — 공책 세 권. ABC는 O C S L T…처럼 획이 단순한 것부터, 숫자는 1 7 4 0…부터.
- 한글 공책은 네 번에 한 번꼴로 **두 글자 낱말**(아기·나무·오이·누나…)이 나와요. 두 글자를 다 써 본 뒤에만.
- 홈 글자를 **길게 누르면** 소리만 들려줘요(시작하지 않음).
- 아이 차례에 오른쪽 아래 **먹 색 세 가지**(쪽빛·먹·청록)를 아이가 골라요.
- 다 쓰면 그 종이가 크게 뜨고, 아이가 **꾹 누르면 붉은 이름 도장**이 찍혀요(책에도 남음). 그 아래 가족 이름 중 오늘 글자가 든 것이 뜨고, 오늘 글자만 진하게.
- 홈 오른쪽 아래 **빈 종이**는 글자 없이 그냥 그리는 종이예요. 책에 같이 남아요.
- 12글자를 한 바퀴 돌면 어른 메뉴 '다음 묶음'에 "한 바퀴 돌았어요"가 뜹니다. 그때 ㅁ을, 다음 바퀴 뒤에 ㅅ을 켜 주세요.

## 없는 것(일부러)

점선, 채점, 지우개, 별, 랭킹, 캐릭터, 결과음(소리는 조각이 맞을 때 '딱', 도장 '쿵', 쓸 때 사각사각뿐), AI, 서버. 모든 데이터는 이 기기 안에만 있어요 — 기기를 바꾸면 종이들도 같이 사라집니다(어른 메뉴의 CSV는 통계만, 글씨 그림은 없음).

## 만든 방법

단일 `index.html`. 글꼴은 리디바탕(리디주식회사, 무료 배포), 조각은 `tools/extract_glyphs.py`가 글꼴 윤곽을 초성·모음 자리에서 잘라 만든 것(`glyphs.json` → `index.html`의 `GLYPHS`에 인라인).
